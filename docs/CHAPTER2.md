# 第2章「薄明の森」― 設計

## 物語

聖堂を抜けた先は、夜明け前の森。ルミナにとって初めての空、風、鳥の声。
グレイは森を抜けて、麓の「消灯の街」（第3章）へ向かうつもりでいる。

森の木々の影からも、影の子らが湧いてくる。けれどこの章でルミナは、自分の光が落とす影が
グレイの足場になることを知る。影はただ怖いだけのものではない――というテーマの最初の手がかり。

最後は丘の上で夜明けを待つ。日が昇るにつれて影の子らは小さくなり、光の中へ還っていく。
丘からは、灯りの消えた灰色の街が見える。

- 導入：「……これが、そら？」「ああ。ここからは 歩いて 街へ向かう」
- 章の終わり：「どうして あの街は 暗いの？」「……灯りを ともすことが 禁じられているんだ」

## 新しい仕掛け ― 影の足場

- 森のところどころに、古い **道標石**（背の高い石）が立っている。
- ルミナが道標石の近くにいると、石の影が **ルミナと反対側** に伸びる。
- 影は石の頭の高さの **足場** になり、**グレイだけが乗れる**（ルミナは光そのものなので、自分の影には乗れない）。
- ルミナが石に **近いほど影は長く**、離れると短くなり、遠すぎると消える。
- ルミナは石より高い段差を越えられないので、ついてくると自然に石のすぐ後ろで止まり、影が一番長くなる。

組み合わせ

1. **はじめての影の足場**：崖の手前の道標石。影を渡ったグレイが向こう岸のレバーで丸太橋を下ろし、ルミナを渡す。
2. **影で登る**：低い位置の道標石の影を踏み台にして高い崖へ。上のレバーで下の木戸を開け、トンネルを回ってきたルミナを引き上げる。
3. **二つの石**：一つ目の影で小島へ渡り、ルミナを受け止めて小島へ呼ぶ。二つ目の石の後ろに立たせて、二つ目の谷を渡る。

## 収集要素

- 影絵の欠片 5 つ：森の記憶ではなく、影の子らがルミナを **外から** 見た初めての景色（空、鳥、朝の色）。
- 灯守りの手記 3 頁：森の道標石は昔の灯守りが立てたもの。影の足場と「光と影は向きが逆」の話。

## 見た目

- 地面：土と草、木の根。背景：夜明け前の空（紺から薄紅へ）、遠い山、木々のシルエット。
- 暗さの覆いは聖堂より薄く、章の最後（夜明け）でさらに明るくなる。
