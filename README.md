# 灯のルミナ — 第1章 プロトタイプ

主人公（老紳士グレイ）が NPC の少女ルミナを連れてダンジョンを進む、SFC 風の謎解きアクション。
体力はなく、ルミナが影に連れ去られて闇の渦に沈むとゲームオーバー。

物語・世界観・登場人物の設定は [docs/STORY.md](docs/STORY.md) にまとめています。

## 遊び方

`index.html` をブラウザで開くだけで動きます（ビルド不要）。スマホ・タブレットではタッチ操作が自動で表示されます。

| キーボード | タッチ | 操作 |
| --- | --- | --- |
| ← → | スティック | 移動（Shift / 2 度押し / スティックを大きく倒すとダッシュ） |
| Z / Space | ジャンプ | ジャンプ（押す長さで高さが変わる） |
| X | 灯竿 | 灯竿を振る（先端の火で影を散らす。3 回で光へ還る／担いでいる影を叩くとルミナを落とす） |
| C | 呼ぶ | ルミナに「待て」⇔「おいで」 |
| ↓（長押し） | スティック↓ | 手を差し伸べる：崖の向こう・高所のルミナを受け止める／2 段の段差から引き上げる |
| ↑ | スティック↑ | レバーを引く |
| Enter / Esc | ❚❚ | ポーズ（再開・最後の灯籠からやり直し・音 ON/OFF） |
| M | ― | 音 ON/OFF |

ゲームパッドにも対応（A=ジャンプ、X=攻撃、Y/B=呼ぶ、RB/RT=ダッシュ）。
スマホは横向き推奨（縦向きでは画面上半分がゲーム、下がコントローラー）。
操作説明の一覧はポーズ画面にあります。

## ステージ構成（`src/stage1.js`）

0. プロローグ（`src/cutscene.js`）… マルタの手紙 → グレイが地下聖堂の最奥でルミナを見つける（Enter / ❚❚ でスキップ）
1. ルミナの部屋と入口の回廊 … 移動・段差・溝・石板と門・レバー（チュートリアル）
2. 降下シャフト（縦スクロール）… ルミナは 4 マスまでなら自分で飛び降りる。最後の 8 マスは受け止めが必要
3. 奈落の回廊 … 3〜4 マスの崖をダッシュジャンプ → 向こう岸で受け止め。影の待ち伏せ
4. 大階段 … 1 段はルミナが自力で、2 段は引き上げ
5. 石板の間 … 2 枚の石板と押し石のパズル
6. 大広間 … 影の 2 波の襲撃を退け、ルミナの光で扉を開けるとクリア

- 石板はルミナ（と押し石）にだけ反応する。「待て」と言うと近くの石板に自分で乗る
- 閉じた門の前でルミナが立ち往生すると、門につながる石板が自分の側にあれば自分で乗りに行く（詰み防止）
- 押し石を壁や縁石に押し付けると崩れて元の位置に戻る（詰み防止）
- ルミナから約 11 マス以上離れて 3.5 秒ほど経つと、彼女の近くに影が出現する
- 灯籠はルミナが通りかかると灯り、チェックポイントになる

## GitHub Pages で公開する

公開中： https://cadmium2525.github.io/tomoshibi/ （ビルド不要。リポジトリのルートをそのまま公開）

1. このフォルダを GitHub リポジトリに push
2. リポジトリの Settings → Pages → Build and deployment を「Deploy from a branch」、ブランチ `main` / フォルダ `/ (root)` に設定
3. `https://<ユーザー名>.github.io/<リポジトリ名>/` で公開される（パスはすべて相対なのでサブディレクトリでも動く）

`.nojekyll` を置いてあるので Jekyll の変換はかかりません。
`assets/`（元画像）と `tools/` も一緒に公開されます。気になる場合は別ブランチに分けてください。

## PWA（ホーム画面に追加・オフライン）

- `manifest.webmanifest` … アプリ名・横向き全画面・アイコン
- `sw.js` … Service Worker。初回表示でゲーム一式をキャッシュし、2 回目以降はオフラインでも起動する
  （キャッシュから即起動しつつ裏で最新版を取得＝更新は「次回起動時」に反映）
- **更新を公開するときは `sw.js` の `VERSION`（例 `lumina-v1` → `lumina-v2`）を上げる** と古いキャッシュが消える
- HTTPS（GitHub Pages）か `localhost` でのみ有効。`?debug` / `?nosw` を付けると登録しない

### アイコン

`icons/` は `assets/chars/lumina/icon.png`（ランタンを持つルミナ）から生成しています。差し替えるときは:

```bash
python tools/make_icons.py path/to/icon.png
```

正方形（1024×1024 推奨）の PNG を渡すと、各サイズ（32 / 180 / 192 / 512 / maskable 512）を書き出します。
Android の丸型マスクで切れないよう、主要な絵は中央 80% に収めてください。

## ファイル

```
index.html            画面・UI・タッチコントローラーの見た目
manifest.webmanifest  PWA マニフェスト
sw.js                 Service Worker（オフライン対応）
icons/                ホーム画面・ファビコン用アイコン
src/core.js           入力（キー / パッド / タッチ）・効果音/BGM・スプライト描画
src/touch.js          タッチコントローラー（スティック・ボタン）
src/world.js          タイル当たり判定・物理ボディ・タイル層の事前描画
src/actors.js         主人公 / ヒロイン AI / 影 / 闇の渦
src/props.js          門・石板・レバー・押し石・灯籠・扉・待ち伏せ
src/stage1.js         ステージ定義と石碑テキスト（{jump} などは入力方法に合わせて置き換わる）
src/cutscene.js       寸劇の仕組み（歩く・話す・ポーズ・暗転）とプロローグの台本
src/game.js           ゲーム進行・カメラ・ライティング・HUD・画面レイアウト
src/assets_gen.js     生成物（全スプライトを base64 で埋め込み）
tools/                アセット生成スクリプトとテスト用ツール
```

## ドット絵の再生成

- 主人公：`assets/chars/oldman/` のシート（walk_sheet / run / jump / idle01）を縮小・減色して 46px のスプライトに
- ルミナ：`assets/chars/lumina/side.png` の立ち絵を「髪・胴・スカート」と脚に切り分け、脚と腕だけ骨格で動かして全ポーズを合成（`tools/heroine.py`）。
  `front.png` はエンディングの正面ポーズに使用
- 影・タイル・背景はスクリプトで描画

素材を差し替えたら:

```bash
cd tools && python build_assets.py
```

（Python 3 + Pillow + NumPy が必要。`walk_old.png` は未使用）
